Download


  • August, 4 2006:
    PlanetDR 2.3.4 Beta release:
    This beta version includes spanish-english language internationalization and a new axis side control panel. And some minor bugs has been fixed. This release is distributed as a Windows and Linux installer.
    Requirements (May not work with other versions):
    • Tomcat 5.5.16 (Windows) (Linux)
    • MySQL 4.1.18 (Windows) (Linux)
    Download: PlanetDR-2.3.4-windows-installer.zip PlanetDR-2.3.4-linux-installer.zip (binaries only)
  • June, 12 2006:
    PlanetDR 2.3.3 Beta release:
    This beta version includes several new features such as content massive upload and SQI/ECL quick search and google-like search . This release is distributed as a Windows and Linux installer.
    Requirements (May not work with other versions):
    • Tomcat 5.5.16 (Windows) (Linux)
    • MySQL 4.1.18 (Windows) (Linux)
    Download: PlanetDR-2.3.3-windows-installer.zip PlanetDR-2.3.3-linux-installer.zip (binaries only)

  • May, 5 2006:
    PlanetDR 2.3.2 Beta release:
    This beta version includes support for ECL and LORI SQI search and server services, supporting IEEE LOM, IMS-CP and WebCT digital resources. This release is distributed as a Windows installer (*nix installer coming soon).
    Requirements: Tomcat 5.5.16 MySQL 4.1.18 (With other versions may not work)
    Download: PlanetDR-2.3.2-windows-installer.zip (binaries only)

Installation


  • Download and install required software (Tomcat and Mysql).
  • Download and install PlanetDR, following the installer instructions.

How to report errors


Send an email to Jordi Pujol with the following information, and we will contact you soon. We already agree feedback with your comments, suggestions and questions.
  • Version of PlanetDR installation.
  • Version of installed Tomcat.
  • Version of installed MySQL
  • $TOMCAT_HOME/logs/catalina.out logs file (in zip or tar.gz archive).
  • $TOMCAT_HOME/webapps/planetdr/WEB-INF/web.xml and dolr-config.xml (if exists).
  • Detailed errors.
IMPORTANT: All this information must NOT be greater than 3MB.
